**สองโหมดในไฟล์เดียว** — ปุ่ม "โหมด" บนแถบ mockup สลับระหว่าง

# 4. ระบบตัวกรอง 9 กลุ่ม (ทำงานจริงจากข้อมูล)

ตัวเลือกทุกกลุ่ม **สร้างจากข้อมูล Add-on จริง ไม่ได้พิมพ์ค้างไว้**

| กลุ่ม | แกน | ที่มาของตัวเลือก |
|---|---|---|
| โจทย์ที่ต้องการแก้ | B | ป้าย `axis: mission` ของทุก Add-on |

# 5. ระบบคะแนน 6 มิติ + NPS

**สามชั้นที่ไม่ปนกัน** — ป้ายกองบรรณาธิการ (ชั้น 1) · คะแนนผู้ใช้ (ชั้น 2) · ตัวเลขการใช้งาน (ชั้น 3)

| มิติ | แสดงที่ |
|---|---|
| R1 ตอบโจทย์การทำงาน · R2 คุณภาพโดยรวม · R3 ลดความซ้ำซ้อน · R4 ใช้งานง่าย · R5 ความเสถียร · R6 การดูแลจากผู้พัฒนา | กราฟแท่ง 6 แท่งในแท็บ "คะแนนและรีวิว" และแถวในตารางเทียบ |
| คะแนนรวม + จำนวนผู้ให้คะแนน | หัวหน้ารายละเอียด และบนการ์ดทุกใบ |
| **NPS** | หัวหน้ารายละเอียด + แท็บคะแนน — มี **tooltip อธิบายวิธีคิด** (9–10 ผู้บอกต่อ · 7–8 ไม่นับ · 0–6 ผู้ไม่แนะนำ · %บอกต่อ − %ไม่แนะนำ · ช่วง −100 ถึง +100 · >0 ดีกว่าแย่ · +30 ดี · +50 ดีมาก) |
| จุดที่คะแนนต่ำสุด | แสดงเปิดเผยทั้งในหน้ารายละเอียดและกำกับ "ต่ำสุด" ในตารางเทียบ |

**กล่องให้คะแนน** — ดาว 6 มิติกดได้ · สไลเดอร์ NPS 0–10 · ช่องประหยัดเวลาต่อวัน · ตัวเลือกแสดงชื่อ รพ./ไม่ระบุชื่อ · แถบยืนยันสิทธิ์ "คุณใช้ Add-on นี้มา 4 เดือน (127 ครั้ง)"

> คะแนนรายมิติของทุก Add-on อ่านจาก **ฟิลด์เดียว** (`dims` + `nps` ต่อ Add-on) ทั้งในตารางเทียบและหน้ารายละเอียด — PHR Monitoring ใช้ค่าตามเอกสารต้นฉบับ (4.8 / 4.5 / 4.9 / 4.1 / 4.4 / 3.8 · NPS +62)

  cover: '…',                      // หัวเรื่องบนภาพปก
  cat: 'ระบบรายงาน',               // แกน A กลุ่มสาขา
  short: '…',                      // คำอธิบายสั้นบนการ์ด
  devName: 'นายบรรจง กิตติสว่างวงศ์',
  sourceType: 'hospital',          // แกน F: bms | vendor | hospital | indie
  verify: 'v2',                    // v0 ยังไม่ยืนยัน · v1 บุคคล · v2 หน่วยงาน · v3 +สัญญา

  iconD: '…',                      // path ไอคอนตามหมวด (fallback)
  tags: [{ label: 'ลดคีย์ซ้ำ', axis: 'mission' }, …],   // many-to-many ทุกแกน
  rating: 4.6, ratingCount: 43,    // ชั้น 2
  hospitals: 125,                  // ชั้น 3 — รพ. ที่ยังใช้อยู่ใน 30 วัน
  price: 'ฟรี',
  dims: [4.8, 4.5, 4.9, 4.1, 4.4, 3.8],   // R1–R6 แหล่งเดียวใช้ทุกหน้า

  award: 'หอเกียรติยศ'             // มีเฉพาะตัวที่เคยได้รางวัล → ป้ายถ้วยบนการ์ด
