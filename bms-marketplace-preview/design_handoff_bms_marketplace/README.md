# Handoff: BMS Marketplace (HOSxP Add-on Marketplace)

**ฉบับที่ 1 · 9 ก.ย. 2569** · repo ต้นทาง: `thabms-hub/marketplace-editorial-board` (branch `main`)

## 1. ภาพรวม (Overview)

หน้า Marketplace สำหรับค้นหา เปรียบเทียบ และขอเปิดใช้ Add-on ของระบบ HOSxP โดยจะฝังใน WebView ของแถบเมนู `/marketplace` ในระบบ `hosxp-marketplace.bmscloud.in.th`

ครอบคลุม 9 หน้า: หน้าแรก (โซน S0–S13), แอปทั้งหมด (ตัวกรอง 9 กลุ่ม), ชุดคัดสรร, คลังความรู้, โปรโมชัน, รายละเอียด Add-on (8 แท็บ), รางวัล, โปรไฟล์ผู้พัฒนา, ตารางเปรียบเทียบ

## 2. เกี่ยวกับไฟล์ในชุดนี้ (About the Design Files)

ไฟล์ HTML ในชุดนี้เป็น **เอกสารอ้างอิงด้านดีไซน์ (design reference)** — prototype ที่แสดงหน้าตาและพฤติกรรมที่ต้องการ **ไม่ใช่ production code ที่จะ copy ไปใช้ตรง ๆ**

งานของนักพัฒนาคือ **สร้างดีไซน์เหล่านี้ขึ้นใหม่ในสภาพแวดล้อมของ codebase จริง** (React, Vue, Blazor, ASP.NET, native ฯลฯ) โดยใช้ pattern และ library ที่โปรเจกต์นั้นใช้อยู่แล้ว — หรือถ้ายังไม่มีสภาพแวดล้อม ให้เลือก framework ที่เหมาะกับโปรเจกต์แล้ว implement ตามดีไซน์นี้

## 3. ระดับความละเอียด (Fidelity)

**High-fidelity (hifi)** — สี ตัวอักษร ระยะ มุมโค้ง เงา และพฤติกรรมทุกอย่างเป็นค่าจริงที่ตั้งใจใช้ ให้ทำตามให้ตรงระดับพิกเซล โดยแทนที่ค่าดิบด้วย token ของ design system ในโปรเจกต์เมื่อมีตัวที่ตรงกัน

ส่วนที่ยังเป็นตัวอย่าง (ไม่ใช่ค่าจริง) ระบุไว้ในข้อ 11 ของ `BMS-Marketplace-Web-Structure.md`

## 5. ปฏิสัมพันธ์และพฤติกรรม (Interactions & Behavior)

| เรื่อง | ข้อกำหนด |
|---|---|
| Hero สไลด์ (S2) | เลื่อนอัตโนมัติทุก 6000ms · หยุดเมื่อ hover · จุดบอกตำแหน่งกดได้ · ปุ่มก่อนหน้า/ถัดไป |
| ชิปโจทย์ / ไทล์วิชาชีพ / ไทล์ความสามารถ | นำไป `/browse` **พร้อมตั้งตัวกรองของป้ายนั้นไว้แล้ว** (ส่งเป็น query param) |
| ตรรกะการกรอง | **ภายในแกนเดียวกัน = OR · ข้ามแกน = AND** |
| ตัวเลขข้างตัวเลือกกรอง | faceted count — นับใหม่ตามตัวกรองอื่นที่เลือกอยู่ + คำค้น |
| ตัวเลือกที่จะได้ผล 0 | ซ่อนอัตโนมัติ ยกเว้นตัวที่ติ๊กอยู่ |
| กลุ่มตัวกรอง | พับ/ขยายได้รายกลุ่ม · พื้นที่เลื่อนสูงสุด 66vh |
| ค้นหาในผลลัพธ์ | match ชื่อ · คำอธิบาย · ชื่อผู้พัฒนา · หมวด |
| เรียงลำดับ | แนะนำ · ใช้อยู่มากที่สุด · คะแนนสูงสุด · ใหม่ล่าสุด · ราคาต่ำสุด |
| ไม่พบผลลัพธ์ | เสนอถอดตัวกรอง + ปุ่ม "ตั้งคำขอพัฒนา" — ห้ามปล่อยหน้าว่าง |
| ตารางเทียบ | สูงสุด 3 รายการ · แถบลอยด้านล่างแสดงรายการที่เลือก · ปุ่มบอกสถานะเมื่อเต็ม |
| เปลี่ยนหน้า | เลื่อนขึ้นบนสุดอัตโนมัติทุกครั้ง |
| ไฮไลต์วงแหวนของ guided tour | ปิดเองเมื่อผู้ใช้ตั้ง `prefers-reduced-motion` |
| Transition มาตรฐาน | 180ms ease สำหรับ hover/สี · 220ms ease สำหรับ transform |
| tooltip ป้าย | แสดงเมื่อ hover/focus · บอก **แกน + ความหมาย** ไม่ใช่แค่ชื่อ |
| Loading / Error | ยังไม่ได้ออกแบบใน prototype — ใช้ pattern ของ codebase (skeleton สำหรับกริดการ์ด, inline error สำหรับตัวกรอง) |

### 5.1 ระบบพาใช้งานผู้ใช้ใหม่ (S0) — 4 ชั้น

| ชั้น | เงื่อนไขแสดง | สถานะที่ต้องเก็บฝั่งเซิร์ฟเวอร์ |

## 6. State ที่ต้องมี (State Management)

| State | ขอบเขต | หมายเหตุ |
|---|---|---|
| `route` + `params` (`addonId`, `devId`) | ทั้งแอป | ควรผูกกับ URL จริงเมื่อขึ้น production (prototype ใช้ state ในหน่วยความจำ) |
| `mode` (`embedded` \| `standalone`) | ทั้งแอป | ใน production คงเป็น `embedded` ตัวเดียว |
| `filters` (แผนที่ axis → เซ็ตค่าที่เลือก) | หน้า browse | serialize เป็น query param เพื่อให้แชร์ลิงก์ได้ |
| `query`, `sort` | หน้า browse | |
| `compare` (อาเรย์ id สูงสุด 3) | ทั้งแอป | คงค่าข้ามหน้า |
| `heroIndex`, `heroPaused` | S2 | |
| `awardRound`, `popularMode`, `knowCat`, `detailTab` | ต่อโซน/หน้า | |
| `onboarding` (4 ธง ตามข้อ 5.1) | ผู้ใช้ | ต้องย้ายไปฝั่งเซิร์ฟเวอร์ |
| `devSearch`, `devSourceFilter` | หน้าโปรไฟล์ผู้พัฒนา | |
| `ratingDraft` (ดาว 6 มิติ · NPS 0–10 · ประหยัดเวลา · ไม่ระบุชื่อ) | กล่องให้คะแนน | ต้อง POST + ตรวจสิทธิ์ว่าเคยใช้จริง |

### 6.1 ข้อมูลที่ต้องดึงจาก API

`GET` รายการ Add-on (สคีมาในข้อ 8 ของเอกสารโครงสร้าง) · รางวัล 4 รอบ · ชุดคัดสรร · คลังความรู้ · โปรโมชัน · ผู้พัฒนา (สร้างจาก `devName` + `sourceType` ได้) · สถิติหน้าแรก 3 ตัว · คะแนนรายมิติจากตาราง `addon_ratings`

## 10. ลำดับงานที่แนะนำ

1. `AddonCard` + design tokens (ข้อ 4.2 และ 7) — ทุกหน้าใช้ต่อ
2. `/browse` + ตัวกรอง 9 กลุ่ม (แกน G โมดูล HOSxP อ่านจากตาราง `MODULES[addonId]`) พร้อมตรรกะ OR-ใน-แกน / AND-ข้ามแกน และ faceted count
3. `/addon/:id` 8 แท็บ + กล่องให้คะแนน 6 มิติ + NPS
4. หน้าแรก S1–S13
5. รางวัล · ชุดคัดสรร · คลังความรู้ · โปรโมชัน · โปรไฟล์ผู้พัฒนา
6. ตารางเทียบ + แถบลอย
7. ระบบพาใช้งาน S0 (ต้องมี state ฝั่งเซิร์ฟเวอร์แล้ว)
8. งานที่ยังค้าง ตามข้อ 11 ของเอกสารโครงสร้าง — modal ยืนยันก่อนขอเปิดใช้, สถิติจาก API จริง, ไอคอนแอป, งานเก็บกวาดข้อมูล
